**Веб‑приложение, позволяющее искать и просматривать видео с видами городов в разное время суток.**
Функциональность
Пользователь может:
ввести название города в поисковой строке;
выбрать время суток (утро, день, ночь) с помощью чекбоксов;
нажать кнопку «Найти» для получения результатов;
просмотреть видео в большом плеере;
увидеть подборку тематических карточек‑превью с описаниями;
загрузить дополнительные карточки по кнопке «Показать ещё».  

**Технологии**
HTML5 - семантическая разметка, шаблоны для динамического контента.
CSS3 - Flexbox и Grid для вёрстки, кастомные стили элементов, адаптивность.
JavaScript — обработка форм, загрузка и отображение данных, управление интерфейсом.
Ключевые компоненты интерфейса
Видео‑плеер - отображает найденное видео.
Форма поиска:
поле ввода города;
группа чекбоксов для выбора времени суток;
кнопка «Найти».
Список карточек - динамически подгружаемые превью видео с заголовком и описанием.
Прелоадер - индикатор загрузки.
Экран ошибки -сообщение при отсутствии результатов или сбоях.
Кнопка «Показать ещё» - подгрузка дополнительных карточек.  

**Видео‑контент и данные для карточек загружаются динамически через JavaScript.**
**При ошибках отображается специальное сообщение.**
**Интерфейс оптимизирован для десктопа.**
